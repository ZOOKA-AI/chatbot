# ACCEPTANCE CRITERIA

لا تُعلن مهمة مكتملة بدون الدليل في العمود الأخير.

| البند | الشرط | الدليل المطلوب |
| --- | --- | --- |
| كل PR | `tsc --noEmit` = 0، vitest بلا فشل جديد، CI gate أخضر | سجل CI |
| أمان | `pnpm audit --audit-level high` = 0؛ CodeQL بلا critical حقيقي | مخرجات الأمر + صفحة Security |
| أسرار | لا سر في الكود؛ المفتاح المسرّب مُدوَّر | secret-scan أخضر + تأكيد المالك |
| قاعدة البيانات | قاعدة فارغة + `scripts/selfhost/migrate.ts` تنتج كل الجداول التي يستخدمها الكود؛ RLS على كل جدول | `select to_regclass(...)` لكل جدول |
| هجرات الإنتاج | تُطبَّق فقط بموافقة المالك وبعد نسخة احتياطية | سجل `_selfhost_migrations` |
| تكامل | حالة `connected` + قراءة واحدة ناجحة + سطر `integration_audit` | لقطة + استعلام |
| ميزة معروضة | تعمل من البداية للنهاية أو عليها شارة COMING SOON | اختبار e2e أو لقطة |
| الجوال | لا تمرير أفقي عند 390px، أهداف لمس ≥ 44px | Playwright mobile project |
| RTL | كل صفحة سليمة في `ar` و`en` | لقطتان لكل صفحة |
| الوكلاء | كل كتابة/إنفاق خارجي تمر بـ `AgentApproval` | اختبار وحدة + سجل |
| النشر | Preview فقط؛ Production بقرار المالك | رابط preview |
