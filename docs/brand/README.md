# ZOOKA AI visual identity

Design workstream, independent of the frozen release candidate (PR #95).

- `BRAND_GUIDE.md` — identity, logo construction, colour with measured contrast, type, agent system
- `LOGO_SPEC.md` — the mark alone, for whoever places it
- `QURAN_SUBBRAND.md` — the educational product's rules
- `SOCIAL_KIT.md` — templates and the claims policy
- `ASSET_INVENTORY.md` — every generated file and what replaces what
- `IMPLEMENTATION_PLAN.md` — six steps, each reversible
- `VISUAL_ACCEPTANCE.md` — what is verified, what is not, what needs approval
- `assets/` — 27 generated SVGs plus `tokens.css` and `tokens.json`
- `tools/generate.py` — regenerates everything from one geometry
