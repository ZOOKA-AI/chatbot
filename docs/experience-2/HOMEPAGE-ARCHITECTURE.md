# HOMEPAGE-ARCHITECTURE — بنية الصفحة الرئيسية

الملف: `components/marketing/landing-page.tsx`. الـ Hero والأقسام الموجودة لم تُعَد كتابتها.

الترتيب بعد التعديل:
1. Header (`site-header.tsx`) — مجموعة جديدة "الموارد" (MCP، AI TV، المدونة، الحسابات)، رابط الدعم، مبدّل السمة.
2. Hero — دون تغيير.
3. الأقسام الحالية (المزايا، التكاملات، الأسعار، Compare) — دون تغيير.
4. جديد: `section#tv` — شريط فيديو ZOOKA AI TV (`VideoStream`) + صف الحسابات الموثقة فقط (`liveAccounts`).
5. Footer جديد بخمسة أعمدة + محدد اللغة والسمة.

روابط المرساة في الهيدر أصبحت `/#section` لتعمل من أي صفحة داخلية.
الفيديوهات ذات الحالة review لا تظهر على الإنتاج (`VERCEL_ENV==="production"`)، فلا يتغير شيء للزوار قبل الموافقة.
