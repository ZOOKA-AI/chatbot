# BRAND-DESIGN-SYSTEM — نظام الهوية والـ Design Tokens

## الشعار
الشعار المعتمد في `public/brand/` (الرمز السداسي Z + الكلمة ZOOKA-AI). لم يُنشأ شعار بديل. الفيديوهات تستخدم نفس ملفات SVG.

## الألوان (Tokens)
| Token | القيمة | الاستخدام |
|---|---|---|
| `--zk-bg` | #080D1B | خلفية الصفحة الداكنة |
| `--zk-surface` | #10182B | البطاقات والأسطح |
| `--zk-primary` | #3978FF | الأزرار الأساسية والروابط |
| `--zk-cyan` | #24D6E6 | التمييز، مؤشرات الحالة |
| `--zk-violet` | #8058F5 | التدرجات والتمييز الثانوي |
| `--zk-text` | #F7F9FF | النص الأساسي على الداكن |
| `--zk-muted` | #A7B5CF | النص الثانوي |

التدرج المعتمد: `linear-gradient(90deg,#24D6E6,#3978FF 45%,#8058F5)`.
في الوضع الفاتح تُستخدم متغيرات shadcn الموجودة (`--background`، `--foreground`، `--muted-foreground`) بدل الألوان الثابتة، وهذا ما أصلح الهيدر في light mode.

## الخطوط
- العربية: Cairo (عناوين) / IBM Plex Sans Arabic (نص).
- اللاتينية: Inter.
- الكود والملصقات التقنية: JetBrains Mono.
قاعدة: لا letter-spacing على النص العربي (يكسر اتصال الحروف). الملصقات ذات التباعد تبقى لاتينية.

## المكوّنات
- بطاقة زجاجية: سطح شفاف 4–6% أبيض، حد 1px بنسبة 10%، ظل أزرق ناعم.
- أهداف اللمس: 44px كحد أدنى (`size-11`).
- حالات التكامل الوحيدة المسموحة: CONNECTED / AVAILABLE / LIMITED / NEEDS SETUP / COMING SOON.
- RTL أولًا: `dir="rtl"` على الحاويات العربية، وعزل النصوص اللاتينية بـ `<bdi>`.
