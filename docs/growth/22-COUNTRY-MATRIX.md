# 22-Country Matrix — Arab World Coverage

The brief asks for a matrix, not for 22 near-duplicate pages. This file is the
decision table that precedes content. It records what we know, what we assume, and
what is unverified.

**Evidence levels used in this file**

- `DATA` — from Search Console, measured 2026-11-23.
- `JUDGEMENT` — an editorial estimate. Not a measurement. Must be re-tested.
- `NOT VERIFIED` — we have no source. Never publish it as a fact.

**Search volumes are absent from this table on purpose.** No keyword tool is
connected to this workspace. Any number here would be invented, and invented
numbers become bad editorial decisions.

## Rules that keep this matrix honest

1. A country page is created only when we have something genuinely local to say:
   a local workflow, a local payment or regulatory detail we have verified, or
   first-hand usage. Otherwise the country is served by a general Arabic article.
2. The "Priority" column is a hypothesis. It is re-scored only from Search Console
   data for that country, never from intuition.
3. Competition and business relevance columns are `JUDGEMENT` until replaced with
   measured data. Nobody should quote them as research.
4. Language expansion (French for Maghreb, English for Gulf) is tested with a
   single page and measured, not rolled out in bulk.
